# Pig Training — Reference Card

> Print this page and tape it to the rig.

```
+================================================================+
|                   PIG TRAINING — DAILY USE                     |
+================================================================+

   STEP 1.  HOPPER + MED-PC  (Shaping/pellet sessions only)
   --------------------------------------------------------
     [ ] Hopper has ~150+ pellets
     [ ] MED-PC.exe is running on the rack PC
     [ ] In MPCLoader, run loader macro -> click  S;1
     [ ] MED-PC screen shows Box 1 with empty counters

   STEP 2.  LAUNCH
   --------------------------------------------------------
     Double-click  Start Training  on the desktop
     A black terminal window opens AND a small
     "Pig Training" window appears.

   STEP 3.  PICK THE TASK
   --------------------------------------------------------
     +----------------------------------------+
     |  Task: [ Shaping (MED-PC pellet)  v ]  |
     |        [ Motor Task - Accuracy      ]  |
     |        [ Motor Task - Reaction Time ]  |
     |                                        |
     |       [   Start Training   ]           |
     +----------------------------------------+
     Read the notes box, then click Start Training.

   STEP 4.  CONFIGURE
   --------------------------------------------------------
     The settings popup opens.
       - Pick the stage to start in
       - Set responses per stage  (defaults are fine)
       - Autoshape: Yes  (for new subjects)
     Click  [ Start ].

   STEP 5.  MONITOR
   --------------------------------------------------------
     Watch the terminal window for reward lines:

       trial started - stage 0
       [REWARD] trial 1: requested=1 delivered=1 status=ok

     Each [REWARD] line = one pellet was delivered.
     Don't touch the keyboard. Don't close anything.

   STEP 6.  END
   --------------------------------------------------------
     - Session completes automatically.
     - Report popup shows stats.  Click  [ Exit ].
     - Terminal says  "Disconnected!"  -- press any key
       to close it.

     To stop early: click the tiny gray square in the
     top-left corner of the touchscreen.

   STEP 7.  DATA
   --------------------------------------------------------
     Shaping       ->  C:\MED-PC\Data\
     Motor Tasks   ->  HamTraining\Data\*.csv

     Don't move or delete these without the lab tech.

+================================================================+
|   Stuck?  Don't poke the terminal.  Call the lab tech.        |
+================================================================+
```
